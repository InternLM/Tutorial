# InternLM 书生·浦语

InternLM 是书生大模型系列的语言模型产品线，从 InternLM 到 InternLM3 持续迭代开源。

## 模型系列

| 模型 | 发布时间 | 亮点 |
|------|---------|------|
| **InternLM3** | 2025.01 | 精炼数据框架，8B 深度思考 |
| **InternLM2.5** | 2024.07 | 百万 Token 长文本 |
| **InternLM2** | 2024.01 | 高质量语料 |
| **InternLM** | 2023.06 | 千亿参数首发 |
