# InternSVG 理论基础

> 本章节 AI + 社区共建中，内容持续完善。

## 为什么是 SVG

矢量图形（Scalable Vector Graphics）由数学描述的路径组成，不依赖像素栅格：

- **无限缩放不失真**：从 16px 图标到户外大屏海报都用同一文件
- **文件小**：一个复杂图标往往只有几 KB，纯 HTML/XML 语法
- **可编程**：直接修改 `<path>`、`<circle>`、`<polygon>` 等标签即可改图
- **可动画**：SVG + CSS/JS 动画可做复杂视觉效果
- **可访问**：屏幕阅读器能读 SVG 里的 `<title>` / `<desc>`

相比位图（PNG/JPEG）：
- 位图放大糊，SVG 无限缩放不糊
- 位图文件大，SVG 文件小
- 位图不可编辑内部结构，SVG 每个元素都可改

## InternSVG 能做什么

InternSVG 把"生成矢量图形"这件事交给大模型，分为三大能力：

### 1. 文本生成 SVG（Text → SVG）

给一段自然语言描述，直接输出 `<svg>` 代码：

```
"画一只戴着眼镜的橙色猫，坐在沙发上"
  ↓
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 200">
  <rect x="20" y="120" width="160" height="60" fill="#8b4513" ... />
  ...
</svg>
```

### 2. 图片转 SVG（Image → SVG）

给一张位图，输出等效的矢量化 SVG。适合把手绘稿、品牌 logo 转成可编辑格式。

### 3. SVG 编辑与优化

在已有 SVG 基础上做增量修改或压缩优化，比如"把猫的颜色改成紫色""给小标题加阴影"。

## 模型架构概览

InternSVG 基于书生生态的视觉-语言统一表示框架，核心模块：

- **编码器**：视觉 Transformer（来自 InternViT）+ 文本 tokenizer
- **对齐层**：Projection Head，将视觉 token 映射到语言空间
- **语言解码器**：在大模型基础上针对 SVG 语法微调
- **格式化头**：保证输出是合法的 SVG/XML 结构
