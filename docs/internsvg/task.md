# InternSVG 矢量图形 AI -- 闯关任务

## 任务说明

通关本课程需要完成以下任务。所有任务均基于 InternSVG 模型，请先按照教材完成环境搭建和模型部署。

## 任务 1：生成一套统一风格的图标集

**要求：**

使用 InternSVG 生成一套 5 个以上统一风格的 SVG 图标。图标需满足以下条件：

1. 至少包含 5 个不同主题的图标（如：首页、搜索、设置、用户、通知等）
2. 所有图标保持一致的设计风格（线条粗细、配色方案、视觉重量）
3. 每个图标的 viewBox 尺寸统一
4. 生成的 SVG 代码语法正确，可在浏览器中正常渲染

**提交：**

- 所有生成的 SVG 文件（至少 5 个）
- 生成脚本的完整代码
- 一张将所有图标放在一起展示的截图，展示风格一致性

## 任务 2：将一张 PNG 图片转为 SVG

**要求：**

选择一张简洁的 PNG 图片（Logo、图标或简单插画），使用 InternSVG 将其转换为 SVG 格式。

1. 输入图片应轮廓清晰、色彩简洁（不要使用照片）
2. 转换后的 SVG 在浏览器中渲染效果应与原图相似
3. 将原始 PNG 和生成的 SVG 并排对比，说明还原度

**提交：**

- 原始 PNG 图片
- 转换生成的 SVG 文件
- 转换脚本的完整代码
- 原图与 SVG 的对比截图

## 任务 3：编辑一个 SVG（改配色或添加动画）

**要求：**

选择任务 1 或任务 2 中生成的一个 SVG，使用 InternSVG 对其进行编辑。以下两个方向任选其一（或两个都做）：

**方向 A -- 配色修改：**
- 使用自然语言指令修改 SVG 的配色方案
- 修改前后的 SVG 都应可正常渲染
- 说明你使用的编辑指令

**方向 B -- 添加动画：**
- 使用自然语言指令为 SVG 添加动画效果（旋转、缩放、淡入淡出等）
- 动画应在浏览器中流畅播放
- 说明你使用的编辑指令

**提交：**

- 编辑前的 SVG 文件
- 编辑后的 SVG 文件
- 编辑脚本的完整代码
- 编辑前后的对比截图（如果是动画，可以录屏或截取关键帧）
