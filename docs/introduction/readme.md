## 实战营简介

书生大模型实战营第七季，围绕 AGI for Science 战略，覆盖六大方向、九门课程，全部免费开放。无论你是在校学生、工程师还是研究者，都能在这里找到适合自己的学习路径。

## 闯关机制

每门课统一三步通关：

1. **学教材** — 阅读课程文档，跟着动手操作
2. **看视频** — 观看配套讲解视频
3. **过考试** — 完成 5 道考核题（60 分及格）

所有课程全部开放，无需按顺序解锁。考试不限重考次数，取最高分。9 门课全部通关，颁发结业证书。

## 适合谁

- 有 Python 基础的在校生或工程师
- 不需要深度学习经验，课程从零讲起

## 学习建议

如果你是新手，建议从 Intern-S1-Pro 开始，了解书生大模型的核心能力，再根据兴趣选择其他课程。

如果你是工程师，可以直接从 Claude Code 或 MCP 入手，快速掌握 AI 编程工具链。

如果你关注科学研究，Intern-S1-Pro + InternVL-U 是重点，体验 AI 在科学领域的前沿应用。
