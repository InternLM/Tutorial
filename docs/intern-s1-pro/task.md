# Intern-S1-Pro 科学大模型 -- 闯关任务

## 任务说明

通关本课程需要完成以下任务。请先按照教材注册账号并获取 API Key。

## 任务 1：用 Python 调用 Intern-S1-Pro API 完成 3 个科学推理任务

**要求：**

使用 Python OpenAI SDK 调用 Intern-S1-Pro API，完成以下三类科学推理任务各一个：

1. **数学题**：一道需要推导过程的数学题（不能是简单计算，需要证明或求解过程）
2. **自然科学题**：一道物理或化学问题（需要原理分析）
3. **代码题**：一道算法或数据结构编程题（模型需输出完整可运行的代码）

每个任务的代码需完整可运行，包含 API 调用和结果打印。

**提交：**

- 三个任务的完整 Python 代码
- 每个任务的模型输出结果截图
- 简要评价模型的回答质量（每个任务 1-2 句话）

## 任务 2：对比普通模式 vs 深度思考模式

**要求：**

选择一道有难度的数学或科学问题，分别用普通模式和深度思考模式调用 Intern-S1-Pro，对比结果。

1. 使用 `extra_body={"chat_template_kwargs": {"enable_thinking": False}}` 关闭深度思考
2. 使用 `extra_body={"chat_template_kwargs": {"enable_thinking": True}}` 开启深度思考
3. 记录两种模式的响应时间和回答质量

**提交：**

- 完整的对比脚本代码
- 两种模式的输出结果截图
- 对比分析（至少包含：响应时间差异、回答完整性差异、推理步骤差异）

## 任务 3：运行一个 Harness 评测

**要求：**

使用 lm-evaluation-harness 框架对一个模型运行标准评测。

1. 安装 lm_eval
2. 选择一个评测任务（推荐 `gsm8k`，约 8500 道数学题）
3. 对本地部署的模型（通过 LMDeploy 部署）或在线 API 运行评测
4. 记录评测结果

如果没有 GPU 资源部署模型，可以使用 Intern-S1-Pro 在线 API 作为评测对象。

**提交：**

- lm_eval 安装成功的截图
- 评测启动命令的截图
- 评测结果截图（包含任务名和准确率）
- 简要分析评测结果（模型在该任务上的表现如何，与预期是否一致）
