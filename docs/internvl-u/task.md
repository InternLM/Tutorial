# InternVL-U 统一多模态 -- 闯关任务

## 任务说明

通关本课程需要完成以下 3 个任务。InternVL-U 是统一多模态大模型，重点考察模型部署能力、三大核心功能的实际使用以及工程化 API 服务的搭建能力。

## 任务 1：模型部署与 API 服务

**目标：** 在 A100 或华为昇腾 Atlas 800T A2 上部署 InternVL-U，搭建可访问的 API 服务。

**要求：**

1. 选择 A100 或华为昇腾 Atlas 800T A2 平台（任选其一）
2. 完成环境配置和模型下载
3. 验证模型加载成功（输出模型参数量和设备信息）
4. 基于 FastAPI 搭建 API 服务，至少包含以下端点：
   - `GET /health` -- 健康检查
   - `POST /understand` -- 图像理解
   - `POST /generate` -- 文生图
   - `POST /edit` -- 图像编辑
5. 验证所有端点可正常调用

**提交：**

- 截图 1：模型加载成功的终端输出（需显示设备类型和参数量）
- 截图 2：API 服务启动成功的终端输出
- 截图 3：调用 `/health` 端点的返回结果

## 任务 2：三大能力实战

**目标：** 使用 InternVL-U 完成图像理解、文生图和图像编辑各 3 个示例。

**要求：**

**图像理解（3 个示例）：**
1. 对一张自然风景照片进行详细描述
2. 对一张包含文字的图片进行 OCR 识别
3. 对一张图表进行视觉问答（提出一个需要分析的问题）

**文生图（3 个示例）：**
1. 生成一张自然场景图像（风景、动物等）
2. 生成一张带有特定艺术风格的图像（油画、水彩、素描等）
3. 使用不同参数（guidance_scale、steps）生成同一提示词的对比图

**图像编辑（3 个示例）：**
1. 对一张图片进行风格转换
2. 修改图片中的某个元素（颜色、物体等）
3. 为图片添加新的元素

**提交：**

- 截图/图像：9 个示例的输入和输出结果（每个示例一组）
- 代码：调用脚本（可以是独立脚本或 Jupyter Notebook）
- 文字说明：每个示例使用的参数和效果评价（每个示例 2-3 句话）

## 任务 3：部署文档

**目标：** 编写一份完整的部署文档，记录从环境配置到服务上线的全过程。

**要求：**

文档需要包含以下内容：

1. **环境信息**
   - 硬件平台（GPU/NPU 型号、显存大小）
   - 操作系统版本
   - Python 版本和关键依赖版本（torch、transformers 等）

2. **部署步骤**
   - 从零开始的完整部署命令序列
   - 每一步的预期输出，方便其他人对照验证

3. **性能数据**
   - 模型加载耗时
   - 图像理解平均推理耗时（统计 5 次以上）
   - 文生图平均耗时（512x512，统计 5 次以上）
   - 图像编辑平均耗时（统计 5 次以上）
   - 显存占用峰值

4. **常见问题**
   - 部署过程中遇到的问题及解决方案（至少记录 2 个）

**提交：**

- 文档：一份 Markdown 格式的部署文档（建议 1-2 页篇幅）
- 性能数据建议用表格呈现，清晰易读
