# Skills 技能编排 -- 闯关任务

## 任务说明

通关本课程需要完成以下 2 个任务。Skills 是 AI 编程效率的核心，重点考察你编写高质量 Skill 文件的能力以及串联多个 Skill 的工作流设计能力。

## 任务 1：编写 3 个自定义 Skill 文件

**目标：** 为一个真实项目编写 3 个不同领域的 Skill 文件，覆盖日常开发中的常见任务。

**要求：**

1. 创建 `.claude/skills/` 目录，编写 3 个 Skill 文件
2. 每个 Skill 需要包含完整的结构：
   - 触发条件：什么时候使用这个 Skill
   - 前置检查：执行前需要确认的条件
   - 执行步骤：具体操作流程（至少 3 个步骤）
   - 质量标准：完成后的验收条件
   - 异常处理：出错时的应对方案
3. 3 个 Skill 需要覆盖不同领域，例如：
   - 代码质量类（代码审查、重构、风格检查）
   - 工程流程类（部署、发布、数据库迁移）
   - 文档类（API 文档生成、变更日志更新）
4. 在 Claude Code 中实际调用每个 Skill，验证其可用性

**提交：**

- 代码：3 个 Skill 文件的完整内容（`.claude/skills/*.md`）
- 截图：在 Claude Code 中调用每个 Skill 的过程和结果（3 张截图）

## 任务 2：实现一个多 Skill 串联的自动化工作流

**目标：** 设计并实现一个至少串联 3 个 Skill 的自动化工作流，覆盖一个完整的业务场景。

**要求：**

1. 编写一个工作流 Skill 文件（`.claude/skills/workflow.md`），串联至少 3 个子 Skill
2. 工作流需要有清晰的阶段划分，每个阶段调用对应的 Skill
3. 包含阶段之间的衔接逻辑（前一个阶段的输出作为下一个阶段的输入）
4. 配置至少 1 个 Hook（`.claude/settings.json`），实现事件驱动的自动触发
5. 在 Claude Code 中完整执行一次工作流，记录全过程

**工作流建议（任选其一或自拟）：**

- **功能开发流**：需求分析 -> 编码实现 -> 测试 -> 审查 -> 提交
- **发布流**：检查 -> 构建 -> 部署 -> 验证 -> 通知
- **Bug 修复流**：问题定位 -> 修复 -> 测试 -> 审查 -> 提交

**提交：**

- 代码：工作流 Skill 文件 + settings.json 中的 Hooks 配置
- 截图：工作流完整执行过程（展示每个阶段的输入输出）
- 文档：一段 200 字以内的说明，描述工作流设计思路和各 Skill 之间的衔接逻辑
