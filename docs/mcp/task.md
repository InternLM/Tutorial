# MCP 工具集成与科学应用 -- 闯关任务

## 任务说明

通关本课程需要完成以下 2 个任务。MCP 是连接 AI 与外部世界的桥梁，重点考察你开发 MCP Server 的工程能力以及将 AI 应用于科学场景的综合能力。

## 任务 1：开发一个 MCP Server

**目标：** 独立开发一个功能完整的 MCP Server，至少包含 2 个 Tool。

**要求：**

1. 使用 TypeScript 或 Python 开发（二选一）
2. 实现至少 2 个 Tool，每个 Tool 需要：
   - 有清晰的功能描述
   - 有参数校验
   - 有完善的错误处理
   - 返回结构化的文本结果
3. （加分项）额外实现 1 个 Resource 或 1 个 Prompt
4. 注册到 Claude Code 并验证功能正常

**主题建议（任选其一或自拟）：**

- **文件管理**：文件搜索 + 文件内容统计 + 目录树生成
- **网络工具**：URL 健康检查 + DNS 查询 + HTTP 请求
- **文本处理**：正则匹配 + 格式转换（JSON/YAML/CSV）+ 编码解码
- **开发辅助**：Git 日志分析 + 代码行数统计 + 依赖检查
- **科学计算**：矩阵运算 + 统计分析 + 曲线拟合

**提交：**

- 代码：MCP Server 完整源码（包括 package.json / requirements.txt）
- 截图 1：`claude mcp list` 显示 Server 已注册
- 截图 2：在 Claude Code 中调用每个 Tool 的过程和返回结果

## 任务 2：Intern-S1-Pro 科学应用

**目标：** 将 MCP 与 Intern-S1-Pro 结合，完成一个科学领域的应用。

**要求：**

1. 选择一个科学领域（物理、化学、生物、数学、工程等均可）
2. 开发或使用一个面向该领域的 MCP Server，提供科学计算工具
3. 在 Claude Code 中，用自然语言描述一个科学问题
4. 让 Intern-S1-Pro 自动调用 MCP 工具进行计算，给出科学分析

**场景示例：**

- **化学**：输入实验温度和反应速率数据，分析动力学参数
- **物理**：输入电路参数，计算电流、电压和功率分布
- **数学**：输入方程组，求解并可视化
- **工程**：输入材料参数，计算应力应变关系
- **生物**：输入种群数据，进行增长模型拟合

**提交：**

- 代码：科学应用 MCP Server 源码
- 截图 1：在 Claude Code 中提问科学问题的过程
- 截图 2：Intern-S1-Pro 调用工具计算并给出科学分析的完整结果
- 文档：200 字以内的说明，描述选择的科学领域、解决的问题和 MCP 的作用
