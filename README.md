## 闯关机制

每门课统一三步通关：

1. **学教材** — 阅读课程文档，跟着动手操作
2. **看视频** — 观看配套讲解视频
3. **过考试** — 完成 5 道考核题（60 分及格）

- 所有课程全部开放，无需按顺序解锁
- 考试不限重考次数，取最高分
- 10 门课全部通关 → 颁发结业证书

## 适合谁

- 有 Python 基础的在校生或工程师
- 不需要深度学习经验，课程从零讲起
